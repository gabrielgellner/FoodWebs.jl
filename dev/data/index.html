Empirical food webs

FoodWebs.jl bundles 26 empirical food webs:

  • cheddar: the 19 webs of the R package cheddar (BSD-2-Clause): Tuesday Lake 1984 and 1986, Ythan Estuary, Benguela, Skipwith Pond, Broadstone Stream, Chesapeake Bay, two Millstream mesocosms and ten pH-gradient streams, with body masses, abundances and taxonomy.
  • williams_martinez_2000: the seven trophic-species webs of Williams & Martinez (2000), the reference webs for the structural properties: Skipwith Pond, Little Rock Lake, Bridge Brook Lake, Chesapeake Bay, Ythan Estuary, Coachella Valley and St. Martin Island.
using FoodWebs

fw = foodweb("williams_martinez_2000/skipwith_pond")
FoodWeb "Skipwith Pond" with 25 species and 197 links
fw.metadata["citation"]
"Warren, P. H. Spatial and temporal variation in the structure of a freshwater food web. Oikos 55, 299–311 (1989)."
first(foodweb_ids(), 5)
5-element Vector{String}:
 "cheddar/benguela"
 "cheddar/broadstonestream"
 "cheddar/chesapeakebay"
 "cheddar/millstream_c4"
 "cheddar/millstream_d4"

A FoodWeb is an AbstractMatrix{Bool}, so every function that takes a web takes it.

Format

Each web is a directory with nodes.csv, whose first column names the species, and trophic.links.csv with columns resource,consumer, one row per feeding link, the layout of cheddar. Each collection has a catalog.toml with every web's title, species and link counts, citation, source and license, and a datapackage.json (Frictionless Data Package) declaring the files' columns, types and foreign keys. read_foodweb reads any directory in this format.

Downloaded webs

The Web of Life and Mangal databases allow use with attribution but do not clearly allow redistribution, so scripts in the repository's data/scripts directory download their food webs to FoodWebs.foodweb_cache, where foodweb_ids and foodweb find them:

julia --project=data/scripts data/scripts/fetch_web_of_life.jl   # 16 webs
julia --project=data/scripts data/scripts/fetch_mangal.jl        # 218 webs

See data/README.md for sources, licenses and how the bundled data were converted.

FoodWebs.FoodWeb — Type
FoodWeb(web; species = string.(axes(web, 1)), name = "", metadata = Dict())

A food web with named species: an S×S binary matrix where web[i, j] == 1 means species j eats species i, together with the species names, a name for the web and a metadata dictionary (for webs read from a catalog, its title, citation, source and license). A FoodWeb is an AbstractMatrix{Bool}, so every function taking a web accepts it.

FoodWebs.foodweb — Function
foodweb(id)

Read the empirical food web id, of the form "collection/web" (see foodweb_ids), as a FoodWeb whose metadata is the web's catalog entry: its title, citation, source and license. For example foodweb("williams_martinez_2000/skipwith_pond").

source
FoodWebs.foodweb_ids — Function
foodweb_ids()

The identifiers "collection/web" of the empirical food webs available to foodweb: the collections bundled with the package and those downloaded to foodweb_cache.

source
FoodWebs.read_foodweb — Function
read_foodweb(dir; name = basename(dir), metadata = Dict())

Read the food web stored in the directory dir, which holds nodes.csv, whose first column names the species, and trophic.links.csv with columns resource,consumer, one row per feeding link. Returns a FoodWeb with the species in the order of nodes.csv.

source
FoodWebs.foodweb_cache — Function
foodweb_cache()

The directory holding downloaded collections of food webs: the environment variable FOODWEBS_CACHE if set, otherwise a scratch space in the first Julia depot. The scripts in the repository's data/scripts directory download webs here.
