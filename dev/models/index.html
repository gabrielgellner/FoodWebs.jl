Food web models

Each generator returns a PredationMatrix for S species at a target connectance C. Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol (default 3%) of C S^2, widened for small webs to the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species, which dynamical models usually need. A target that cannot be met throws an ArgumentError instead of resampling forever.

Mean connectance with acceptance turned off (tol = Inf) matches the target for every model, which checks each model's parameterization separately from the acceptance step.

FoodWebs.may_network — Function
may_network([rng], S, C; tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a random S species web with connectance C, following: May, R. M. Will a large complex system be stable? Nature 238, 413–414 (1972).

Each pair of species is linked with probability 2CS / (S - 1), and the direction of the link (who eats whom) is chosen at random. There are no self links or mutual predation. As these are random graphs rather than food web models, all but sparse webs usually have no basal species, so basal_paths = true is rarely satisfiable.

Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol of C S^2, widened for small webs to include the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species (see disconnected_from_basal).

FoodWebs.niche_network — Function
niche_network([rng], S, C; tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a niche model web with S species and connectance C, following: Williams, R. J. & Martinez, N. D. Simple rules yield complex food webs. Nature 404, 180–183 (2000).

Each species i has a niche value η_i ~ U(0, 1) and eats every species whose niche value lies in the interval of width r_i = x η_i, x ~ Beta(1, 1/2C - 1), centered at c_i ~ U(r_i / 2, η_i). Species are ordered by niche value.

Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol of C S^2, widened for small webs to include the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species (see disconnected_from_basal).

FoodWebs.generalized_niche_network — Function
generalized_niche_network([rng], S, C, diet; tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a generalized niche model web with S species, connectance C, and diet contiguity diet ∈ [0, 1], following: Stouffer, D. B., Camacho, J. & Amaral, L. A. N. A robust measure of food web intervality. PNAS 103, 19015–19020 (2006).

Each species keeps a fraction diet of its niche model range as a contiguous interval, and makes up the missing links with cascade style links to random lower ranked species. With diet = 1 this is the niche model without cannibalism, and with diet = 0 it is close to the generalized cascade model.

FoodWebs.nested_hierarchy_network — Function
nested_hierarchy_network([rng], S, C; tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a nested-hierarchy model web with S species and connectance C, following: Cattin, M.-F., Bersier, L.-F., Banašek-Richter, C., Baltensperger, R. & Gabriel, J.-P. Phylogenetic constraints and adaptation explain food-web structure. Nature 427, 835–839 (2004), as described by Stouffer, D. B., Camacho, J., Guimerà, R., Ng, C. A. & Amaral, L. A. N. Quantitative patterns in the structure of model and empirical food webs. Ecology 86, 1301–1311 (2005), Appendix B.

Species are ordered by niche value, and each species i eats round(S r_i) species, with r_i drawn as the niche model's range. Species pick their prey in order of niche value:

  1. The first prey j is a random species with a lower niche value.
  2. If another species also eats j, further prey come from the prey of j's consumer group: the consumers of j and the consumers sharing a prey with them. Only species with lower niche values than i are drawn.
  3. Then species with lower niche values that have no predators yet.
  4. Then species with niche values greater than or equal to that of i, including i itself.
  5. Then any remaining species with lower niche values, so every species gets its full diet.

Step 5 is not in the published description and is rarely needed. With steps 1–4, about 8% of links go to species with niche values at least that of the predator, as Stouffer et al. report (their Fig. 4). Diets are not intervals, unlike the niche model.

Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol of C S^2, widened for small webs to include the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species (see disconnected_from_basal).

FoodWebs.minimum_potential_niche_network — Function
minimum_potential_niche_network([rng], S, C, f; tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a minimum potential niche model web with S species, connectance C and fraction f ∈ [0, 1) of forbidden links, following: Allesina, S., Alonso, D. & Pascual, M. A general model for food web structure. Science 320, 658–661 (2008).

Each species has a niche interval as in niche_network. The species at the two ends of the interval are always prey, and each species inside it is a prey with probability 1 - f, so diets need not be intervals. With f = 0 this is the niche model, and the same rng gives the same web.

The niche intervals are drawn at a potential connectance above C, chosen so that the expected connectance after forbidding links is C. It accounts for the kept ends of each interval (Johnson et al. 2014, SI 1.5), using a binomial approximation for the number of species in an interval. Mean connectance is within a few percent of C while the potential connectance stays below about 0.3, beyond which the niche model's intervals lose range past niche value 1. Throws an ArgumentError if C needs a potential connectance of 0.5 or more.

Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol of C S^2, widened for small webs to include the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species (see disconnected_from_basal).

Johnson, S., Domínguez-García, V., Donetti, L. & Muñoz, M. A. Trophic coherence determines food-web stability. PNAS 111, 17923–17928 (2014).

FoodWebs.probabilistic_niche_network — Function
probabilistic_niche_network([rng], η, c, r; a = 1, p = 2)
probabilistic_niche_network([rng], S, C; a = 1, p = 2, tol = 0.03, maxiter = 10_000, basal_paths = false)

Generate a probabilistic niche model web (Williams, Anandanadesan & Purves 2010), where each species i eats each species j independently with probability P[j, i] from probabilistic_niche_probabilities.

Given niche values η, feeding centers c and feeding ranges r, it draws one web from these probabilities.

Given S and C, it draws the parameters as in niche_network. The kernel integrates to a Γ(1 + 1/p) r[i] (a √π r[i] / 2 for the Gaussian), against r[i] for the niche model's interval, so the ranges are drawn at the niche model connectance C / (a Γ(1 + 1/p)) to give C S^2 links on average. This must be below 0.5. Webs are resampled until they are connected and their number of links L satisfies abs(L - C S^2) <= max(tol C S^2, 1/2): within a relative tolerance tol of C S^2, widened for small webs to include the whole number of links nearest C S^2. With basal_paths = true they are also resampled until every species has a feeding path up from a basal species (see disconnected_from_basal).

FoodWebs.probabilistic_niche_probabilities — Function
probabilistic_niche_probabilities(η, c, r; a = 1, p = 2)

The link probabilities of the probabilistic niche model, following: Williams, R. J., Anandanadesan, A. & Purves, D. The probabilistic niche model reveals the niche structure and role of body size in a complex food web. PLoS ONE 5, e12092 (2010).

Returns the S×S matrix P where P[j, i] is the probability that species i eats species j (prey are rows, predators are columns),

P[j, i] = a exp(-|(η[j] - c[i]) / (r[i] / 2)|^p),

for niche values η, feeding centers c and feeding ranges r. The paper uses the Gaussian kernel p = 2. The probability peaks at a when η[j] == c[i], and as p grows the kernel approaches the niche model's interval of width r[i] centered on c[i]. A species with r[i] == 0 eats nothing. Williams et al. fix a = 0.9999 when fitting, as a = 1 gives links outside the data a log-likelihood of -Inf.

Allometric diet breadth model

The allometric diet breadth model of Petchey et al. (2008) predicts who eats whom in a given set of species from their body masses, where the models above generate random webs. Each consumer ranks its resources by profitability, energy over handling time, and eats the most profitable ones up to the diet that maximizes its rate of energy intake. Encounter rates, energy contents and handling times are power laws of the consumer and resource masses. With RatioHandling, a consumer cannot eat resources heavier than a fraction b of its own mass, so the web has no loops and no cannibalism, and each diet is an interval of resource masses centered near b / 2 of the consumer's mass. PowerHandling lets consumers eat heavier resources but gives every consumer the same ranking of resources.

fit_diet_breadth fits the model to an observed web with body masses, holding the number of links at the observed number and maximizing the fraction of them in the right place. Petchey et al. predict 57% of the Benguela links with ratio handling times and 42% with power handling times; the fit below finds parameters that do better on the cheddar version of the web.

fw = foodweb("cheddar/benguela")
ratio = fit_diet_breadth(Xoshiro(1), fw; handling = :ratio)
power = fit_diet_breadth(Xoshiro(1), fw; handling = :power)
(ratio = round(ratio.fraction, digits = 2), power = round(power.fraction, digits = 2))
(ratio = 0.63, power = 0.48)

The fitted model comes close to the observed omnivory and spread of generality. Its web has no loops, since every consumer eats lighter species, while 41% of the Benguela species are in loops:

FoodWebs.diet_breadth_network — Function
diet_breadth_network(M; handling, a = 1, ai = 0, aj = 0, e = 1, n = 1, ni = -0.75,
                     N = nothing, consumers = trues(length(M)))
diet_breadth_network(fw::FoodWeb; kwargs...)

The food web of the allometric diet breadth model, following: Petchey, O. L., Beckerman, A. P., Riede, J. O. & Warren, P. H. Size, foraging, and food web structure. PNAS 105, 4191–4196 (2008).

Species i has body mass M[i]; for a FoodWeb, the masses are its "M" trait. The model scales the foraging variables of consumer j and resource i with their masses:

  • abundance N_i = n M_i^ni, unless the abundances N are given;
  • energy content E_i = e M_i;
  • attack rate A_ij = a M_i^ai M_j^aj, and encounter rate λ_ij = A_ij N_i;
  • handling time H_ij from handling, a RatioHandling or PowerHandling.

Each consumer ranks the resources it can handle (finite H_ij) by profitability E_i / H_ij and eats the k most profitable, choosing k to maximize its rate of energy intake Σ λ_ij E_i / (1 + Σ λ_ij H_ij) (the contingency model of optimal foraging). Equivalently, it adds resources in order of profitability while the next one is more profitable than the intake rate of the diet so far. Ties in profitability go to the lower index.

Every consumer eats at least one resource when it can handle any. Only the species marked in consumers eat, so producers can be left without a diet; for a FoodWeb the default is the species with prey in the web.

The diets depend on a n h, ai + ni and aj and the handling exponents, and not on e: scaling encounter rates up by a factor and handling times down by the same factor scales every intake rate and leaves the diets unchanged. Larger a narrows every diet.

FoodWebs.RatioHandling — Type
RatioHandling(; b, h = 1)

The ratio handling time function of Petchey et al. (2008): consumer j handles an individual of resource i in time H_ij = h / (b - M_i / M_j) when M_i / M_j < b and cannot eat it otherwise. Handling time rises from h / b for tiny resources to infinity at the mass ratio b, so the most profitable resource of consumer j has mass b M_j / 2.

source
FoodWebs.PowerHandling — Type
PowerHandling(; hi, hj, h = 1)

The power handling time function of Petchey et al. (2008): consumer j handles an individual of resource i in time H_ij = h M_i^hi M_j^hj. Every consumer finds the smallest resource most profitable when hi > 1 and the largest when hi < 1.

FoodWebs.fit_diet_breadth — Function
fit_diet_breadth([rng], fw::FoodWeb; handling = :ratio, kwargs...)
fit_diet_breadth([rng], web, M; handling = :ratio, consumers, starts = 20,
                 steps = 300, ni = -0.75)

Fit the allometric diet breadth model (diet_breadth_network) to the observed web with body masses M, maximizing the fraction of links predicted correctly, as Petchey et al. (2008) did. Only the species in consumers eat (default: the species with prey in web).

The model's number of links falls as the attack rate constant a grows, so for every value of the other parameters the fit sets a by bisection to give the number of links L nearest the observed number; the fraction correct is then the number of predicted links present in web over L, or over the observed number of links when the prediction has more. The fit searches the remaining parameters, ai and aj and then b for handling = :ratio or hi and hj for handling = :power, by hill climbing from starts random starting points, each for steps random moves. It holds h = n = e = 1 and the abundance exponent ni, since the diets depend on a n h and ai + ni only.

Returns a named tuple with the predicted web, the fitted parameters (the keyword arguments of diet_breadth_network, including handling), the number of predicted links correct in web, and the fraction correct.
